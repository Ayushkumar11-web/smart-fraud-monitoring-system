# Smart Fraud Monitoring System

## Overview

Smart Fraud Monitoring System is a full-stack web application developed to monitor banking transactions and identify suspicious activities. The system allows administrators to manage customers, accounts, transactions, fraud alerts, business rules, and reports through a secure dashboard.

---

## Features

- Secure Admin Login using JWT Authentication
- Dashboard with Charts and Statistics
- Customer Management (CRUD)
- Account Management (CRUD)
- Transaction Management
- Fraud Alert Monitoring
- Rule Management
- Report Generation
- Protected Routes
- Logout Functionality
- Responsive Bootstrap UI
